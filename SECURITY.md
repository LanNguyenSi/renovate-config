# Security policy

The preset decides which dependency updates Renovate proposes in every
repository that extends it. A change that lets updates through without the
release-age wait, enables automerge or touches npm `overrides` is a security
problem even when it looks like a plain defect.

## Reporting

Please **do not** open a public issue for security reports. Use the
"Report a vulnerability" form on the Security tab of the repository
(private vulnerability reporting), or email **contact@lan-nguyen-si.de**.

You will get an acknowledgement within 72 hours.
